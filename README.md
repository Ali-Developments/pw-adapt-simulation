# PW-ADAPT — Interactive Produced Water Treatment Simulation

An interactive digital simulation demonstrating the **PW-ADAPT** (*Produced Water Adaptive Treatment*) system concept for upstream oilfield produced-water management.

## Live Simulation
- **Public URL**: [https://ali-developments.github.io/pw-adapt-simulation/](https://ali-developments.github.io/pw-adapt-simulation/)

## Overview
PW-ADAPT presents a modular, human-supervised approach to produced-water treatment:
1. **Sense**: Characterize incoming water quality (oil content, turbidity, conductivity, temperature, pressure).
2. **Decide**: Compare candidate treatment routes against regulatory reuse standards (reinjection, cooling, irrigation) and evaluate operational cost and energy intensity.
3. **Approve & Treat**: Operator reviews and authorizes the recommended sequence before treatment actuation.
4. **Verify**: Post-treatment verification cell checks effluent quality against compliance thresholds.
5. **Fail-Safe Response**: Real-time safety interlocks, overpressure detection, and automated safe-state isolation.

## Interactive Features
- **Interactive Prototype Rig**: Click any vessel, valve, pump, sensor cell, or control module to inspect technical specifications, live process telemetry, and safety boundaries.
- **Process Actions**: Start the simulated run, observe dynamic hydraulic flow and separation sparging, inject overpressure faults, and test emergency shutdown responses.
- **Live Process Simulator**: Interactive P&ID process flow model with real-time feed sliders, route comparison matrices, removal efficiencies, and cost-benefit analysis.

## Prototype Notice
*This deployment is an interactive engineering prototype and simulation environment. Displayed sensor telemetry and removal efficiencies represent modeled scenario values intended to demonstrate system behavior and supervisory control logic.*
